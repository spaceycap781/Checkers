# Java Checkers Game

This project was developed as my final project for AP Computer Science A during my senior year of high school. Using Java and Swing, I created an interactive two-player Checkers game with a graphical user interface.

The game features an 8×8 board, turn-based gameplay, valid move highlighting, piece capturing, multiple jumps, king promotion, and automatic winner detection. Players can interact with the board using their mouse and restart the game at any time.

Through this project, I applied object-oriented programming concepts, including classes, methods, arrays, loops, conditional statements, and event handling. This project helped strengthen my understanding of Java programming, game logic, and graphical user interface development.

**Technologies Used:** Java, Java Swing, Java AWT

**Course:** AP Computer Science A — Senior Year Final Project
